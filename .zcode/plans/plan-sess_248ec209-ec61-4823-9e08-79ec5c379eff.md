# ATEQ F620 双腔 + 激光打码 双工位项目 — 实施计划（修订版）

## 1. 需求（已逐项确认）

- **两个工位完全独立**：每工位 = 西门子 S7-200 Smart（snap7，以太网）+ ATEQ F620 双腔（正负压，串口 COM）+ 激光打码机 1 台
- **同一套代码装 A、B 两台电脑**，每个实例只控制本工位（本工位 PLC + 本工位 ATEQ + 本工位激光 + 单工位界面）
- **MySQL 8.4 在 A、B 电脑上都装（localhost），相互独立**；两电脑间网线仅用于可选的跨工位只读查询/远程维护，不互写数据
- 流程（**无扫码**）：放件 → PLC 启动（上升沿）→ 第一次测试 → 第二次测试 → **正压、负压都合格，才输出打码文本** → 激光打码 → 完成；任一 NG：不打码、记录直接结束
- 打码文本字段：**日期、产品型号、测试压力1、泄漏量1、测试压力2、泄漏量2、结果、操作工**；**输出后 10 秒自毁清空**（时长可配置）
- 激光触发：**文件 + PLC 启动位脉冲**（同 heating 项目）
- **PLC 点位表现在不提供、稍后提供**：点位全部做成配置文件/占位表，电气点位表到位后只填配置、不改代码
- **NG/OK 样件验证逻辑和时效倒计时：与 Morocco 项目完全一致**（样件测试默认不打码，现场可确认）
- 本机开发+审核（simulate 模式 + pytest 验证），实施稍后部署到现场电脑

## 2. 基线选择

以 `xiezhong-Morocco-2-stations` 仓库**根目录 `app/`**（现场验收过的 Python 版）为基线，可直接复用：

- Snap7Plc：S7-200 SMART + python-snap7，写使能安全策略（CapabilityPolicy）
- SerialAteq：串口 Modbus 风格帧（9600 8E1、0x30 实时块、程序号读写、响应身份强校验）；测试由 PLC 硬件启动、上位机只监控
- StationController 状态机（IDLE→TEST_1→WAIT_2→TEST_2→完成/FAULT）+ CycleJournal 断电恢复 + intent/commit 落库
- 四模式 simulate→characterization→shadow→live + LIVE 预检 + 安全停机
- **NG/OK 样件验证 + 校准时效倒计时**整块逻辑原样保留
- MySQL repository、PySide6 复刻 UI（多语言）、install_mysql84.ps1 部署脚本

激光打码从 `xiezhong-heating` 的 `heating_python/laser_files.py`（原子写+回读字节校验+延时清空）和 `live_laser.py`（PLC 位脉冲+写校验+回读诊断）移植，按新需求简化（单文本文件、无客户码分配模块）。

## 3. 目标架构（两套镜像、相互独立）

```
工位A电脑（镜像）                        工位B电脑（镜像）
┌──────────────────────────┐          ┌──────────────────────────┐
│ 程序实例A（单工位模式）    │          │ 程序实例B（单工位模式）    │
│  MySQL 8.4 (localhost)   │          │  MySQL 8.4 (localhost)   │
│  PLC A (snap7)           │   网线    │  PLC B (snap7)           │
│  ATEQ A (COMx)           │ ←可选只读→ │  ATEQ B (COMx)           │
│  打码TXT → 激光A软件 → 激光机A│        │  打码TXT → 激光B软件 → 激光机B│
└──────────────────────────┘          └──────────────────────────┘
```
单工位周期：PLC 启动边沿开周期 → 监控第一次测试 → 监控第二次测试 → **双合格** → 从本地库提交后的记录生成打码文本（保证"打的数据=存的数据"）→ 原子写 TXT（回读校验）→ snap7 脉冲本工位 PLC 激光启动位 → **10 秒后清空 TXT** → 周期完成（marked）。

## 7. 风险与对策

- **无扫码→无产品序列号**：追溯主键为"工位+时间戳"（cycle_id）；后续若要序列号可再加 DB 列和来源
- **PLC 点位未定**：simulate/单测不受影响；LIVE 预检在点位表填入前会按设计拒绝放行（fail-closed）
- **ATEQ 由 PLC 硬件启动测试**：需 PLC 程序按此逻辑编写（与 Morocco 一致），上位机只监控
- **打码文件 10 秒清空**：防止下一件误用旧内容（heating 验证过的做法），时长可配置
