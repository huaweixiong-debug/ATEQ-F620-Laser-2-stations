# 校准样件验证操作说明（NG 首件 / OK 二件）

适用设备：ATEQ F620 双腔气密检测 + 激光打码（A / B 双工位）
适用范围：校准倒计时到期后的样件验证作业
日期：2026-10-11

---

## 一、概述

为保证检测设备的测量能力持续可靠，设备设有**校准倒计时**。倒计时到期后，本工位必须先完成一件 **NG 样件**和一件 **OK 样件**的测试，验证设备能够正确识别不合格品与合格品，之后才能继续正常生产与激光打码。

验证期间：

- 样件**只测试、只记录，不打码**（激光打码机不动作）。
- A、B 两个工位各自独立验证，互不影响、互不等待。

流程总览：

```
校准倒计时到期
   ↓
点击「启动验证」（单测/双测模式此时锁定，验证过程中不可更改）
   ↓
【NG 首件】放 NG 样件 → PLC 启动 → 判定为 NG → 通过
   ↓
【OK 二件】放 OK 样件 → PLC 启动 → 判定为 OK → 通过
   ↓
校准完成：清除指示、倒计时重新开始，工位恢复正常生产与打码
```

---

## 二、验证倒计时

| 项目 | 说明 |
| --- | --- |
| 计时起点 | 上一次验证完成并恢复生产之后开始计时 |
| 到期表现 | 工位出现「校准到期」提示，按钮显示「启动验证」 |
| 到期后可否测试 | **可以**。设备能正常启动并完成 ATEQ 测试 |
| 到期后可否打码 | **不可以**。上位机不建立生产记录、不生成打码内容，激光打码机收不到内容，作业无法继续 |
| 倒计时复位 | 只有**验证全部通过**后才重新开始计时；点「启动验证」本身不会重置倒计时 |

> 说明：校准到期后如果直接放生产件启动测试，该件不会被打码，也不会进入正常生产记录。请先完成样件验证。

---

## 三、NG 首件

1. 点击「启动验证」后，界面提示「**请放 NG 首件**」。
2. 放入 NG 样件，按 PLC 启动测试。
3. 判定以**本次测试的最终结果**为准：

| 测试情况 | 判定 |
| --- | --- |
| 负压腔测出 NG（仪器自动终止，只测一腔） | **通过** |
| 负压腔 OK，继续测正压腔，正压腔测出 NG | **通过** |
| 最终结果为 OK | 不符合预期，需重测 |

4. 通过后，界面转为提示「**请放 OK 二件**」，进入下一步。

NG 样件通过后样件**不打码**。

### 不符合预期时怎么办

界面提示「**样件验证不符合预期：要求 NG，实际 OK**」。

- 本次记录会保留，但验证**不推进**，仍停留在「等 NG 首件」。
- 请重新放 NG 样件测试，**下一次 PLC 启动会自动重新开始 NG 首件测试**，不需要额外操作。
- 失败的结果不会被当作通过。

### 仪器报警不算 NG

测试过程中若仪器报压力高、压力低或其他报警（未测出泄漏值即终止），**不算作 NG 验证通过**，按设备故障处理：

- 界面提示故障，需**复位**后重新测试；
- 复位后仍停留在「等 NG 首件」，重测即可。

> 只有真正测出不合格（NG）的样件结果，才算 NG 验证通过。

---

## 四、OK 二件

1. NG 首件通过后，界面提示「**请放 OK 二件**」。
2. 放入 OK 样件，按 PLC 启动测试。
3. 判定规则：

| 模式 | 测试情况 | 判定 |
| --- | --- | --- |
| 双测（标准） | 负压腔 OK → 正压腔 OK（共两次测试） | **通过** |
| 双测 | 任一腔测出 NG | 不符合预期，需重测 |
| 单测 | 负压腔一次 OK | 通过 |

4. 双测时，负压腔 OK 后**不会立即通过**，界面会显示「负压 OK，等待正压」，需要继续完成正压腔测试（第二次 PLC 启动），两腔都合格才算通过。**两次测试属于同一件样件、同一条记录。**

### 不符合预期时怎么办

界面提示「**样件验证不符合预期：要求 OK，实际 NG**」。

- 本次记录保留，验证不推进，仍停留在「等 OK 二件」。
- 请重新放 OK 样件，**下一次 PLC 启动会自动从负压腔重新开始**（双测需重新走完两腔）。
- NG 首件的通过结果不受影响，不需要重做 NG 首件。

OK 样件通过后同样**不打码**。

---

## 五、复位

复位方式有两种，作用相同：

- **PLC 面板复位**（设备面板上的复位按钮）——日常使用这一种；
- **界面上的「复位」按钮**——仅在界面出现错误/异常提示时显示。

复位的作用：

- 中止并归档当前工件/周期，清除界面报警，重新连接 PLC，恢复可写入状态；
- 复位后工位回到待启动状态，可以开始下一次测试；
- PLC 面板复位后工位**一定**回到待启动状态，可以直接进行下一次测试。

复位**不会影响**的内容：

| 项目 | 复位后 |
| --- | --- |
| 验证进度 | 保持不变。已通过的 NG 首件仍然有效，复位后仍在当前阶段继续（例如正在等 OK 二件，复位后仍是等 OK 二件） |
| 单测/双测模式 | 保持验证开始时锁定的模式，不因复位改变 |
| 「不符合预期」的结果 | 不会被算作通过；复位后仍然是同一阶段，需要重测 |
| 校准倒计时 | 不重置，验证完成后才重新开始计时 |

复位后**需要**重新测试：

- 仪器报警或通讯故障导致的故障状态，复位后按**同一阶段**重测；
- 若复位时正在等某一腔测试结果，该次测试作废，重新放件测试；
- 双测 OK 样件若在负压腔 OK 后复位，需从负压腔重新开始。

> 建议：样件测试过程中不要按复位。只有在出现故障提示、或确实需要中止当前工件时才复位。

---

## 六、再次进入正常测试

OK 二件通过后，校准验证完成，设备自动完成以下动作：

1. 归档样件周期；
2. 清除「校准到期」等指示（全部熄灭）；
3. **校准倒计时重新开始**；
4. 工位恢复正常生产状态。

之后的操作与正常生产完全一致：

- 放生产件 → PLC 启动 → 第一次测试（负压腔）；
- 负压腔 OK → 继续第二次测试（正压腔）；
- 两腔都合格 → 自动输出打码内容并触发激光打码；
- 任一腔 NG → 记录 NG，不打码，下一件正常启动。

> 只有「对应标签已正确生成」这一条路径会触发激光打码；样件测试与不合格品都不会打码。

## 七、界面提示一览

| 界面提示 | 含义 | 操作 |
| --- | --- | --- |
| 校准到期，请点击启动验证 | 倒计时到期，需要验证 | 准备好 NG 样件后点击「启动验证」 |
| 请放 NG 首件 | 等待 NG 样件 | 放 NG 样件，PLC 启动 |
| 请放 OK 二件 | NG 首件已通过 | 放 OK 样件，PLC 启动 |
| 负压 OK，等待正压 | 双测 OK 样件已完成负压腔 | 继续完成正压腔测试 |
| 样件验证不符合预期：要求 NG，实际 OK | NG 首件未通过 | 重放 NG 样件，重新启动 |
| 样件验证不符合预期：要求 OK，实际 NG | OK 二件未通过 | 重放 OK 样件，重新启动（双测从负压腔开始） |
| 验证完成 | 样件验证已通过 | 无需操作，直接转正常生产 |
| 校准计时 HH:MM | 正常生产中，显示距下次校准的剩余时间 | 无需操作 |

## 八、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 校准到期后测试能跑，但不打码 | 验证未完成，生产与打码被锁定 | 完成 NG 首件 + OK 二件验证 |
| 放的是生产件，却提示「要求 NG，实际 OK」 | 验证期间放入的工件会被当作样件判定 | 按提示重新放对应的 NG / OK 样件 |
| OK 二件负压腔 OK 后没有通过 | 双测需两腔都合格 | 继续完成正压腔测试 |
| 样件测试时仪器报警 | 仪器报警不视为 NG | 复位后按同一阶段重测 |
| 复位后仍提示「请放 OK 二件」 | 复位不改变验证进度 | 正常现象，继续完成 OK 二件 |
| 界面提示需要「管理员恢复」 | 断电或故障残留了未完成周期 | 由管理员在「手动」页的「管理员恢复」中填写处理原因后归档，之后可继续测试（验证阶段不变） |
| 验证通过后想切换单测/双测 | 模式在验证期间锁定 | 验证完成后、下一个周期前切换（生产须使用双测） |
